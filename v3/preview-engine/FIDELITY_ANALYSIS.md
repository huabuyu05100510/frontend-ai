## 五、根因分析

### 问题 1：颜色丢失（全局）
- **根因**：LibreOffice 对 OOXML 主题色（theme colors）的映射与 Microsoft Office 不一致
- **影响**：蓝色、绿色等强调色 → 灰色/黑色
- **可行解决**：检查 LibreOffice 是否有主题色映射配置；或考虑在 PDF 后处理中做颜色校正

### 问题 2：PPT 内容丢失（转换2）
- **根因**：LibreOffice Impress 对该 PPTX 的特定元素（可能是 SmartArt、自定义形状或嵌入对象）解析失败
- **影响**：整个幻灯片几乎空白
- **可行解决**：需要具体分析该 PPTX 的结构，确认是哪种元素导致

### 问题 3：表格结构退化（XLSX）
- **根因**：LibreOffice Calc 打印/导出 PDF 时默认不显示网格线
- **影响**：单元格边界不可见
- **可行解决**：LibreOffice 宏或配置设置打印网格线

### 问题 4：字体（全局）
- **根因**：macOS 未安装 Windows 中文字体（SimSun、SimHei、Microsoft YaHei）
- **影响**：字体度量不同 → 换行位置不同 → 布局偏移
- **可行解决**：安装 Windows 字体到 macOS

## 六、改进方向

### 方向 A：优化 LibreOffice 配置（低成本）
- 安装 Windows 中文字体到 macOS
- 配置 LibreOffice 打印网格线
- 调整 PDF 导出参数
- 预期提升：4.5 → 7/10

### 方向 B：换用 Microsoft 官方渲染（高成本）
- Microsoft Graph API / Office Online
- WPS 在线预览
- OnlyOffice 后端
- 预期提升：可达 9-10/10

### 方向 C：混合方案
- DOCX 用 mammoth/puppeteer 精确渲染（已移除，可恢复优化版）
- XLSX 用自研 OOXML 解析器直接渲染（现有路径 A）
- PPTX 需要外部服务
