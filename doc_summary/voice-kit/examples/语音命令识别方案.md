# 语音命令识别方案 - 口音容错设计

> 针对2048游戏的语音控制场景，解决口音、同音词、表达多样性问题

---

## 一、问题分析

### 1.1 口音问题

| 地区 | 标准音 | 口音变体 | 示例 |
|------|--------|---------|------|
| 北方 | shàng | shàng | 上 |
| 南方 | shàng | sáng | 上→桑（ang/an不分） |
| 四川 | shàng | sàng | 上→丧（sh/s不分） |
| 福建 | zuǒ | zuò | 左→作（声调差异） |
| 广东 | yòu | yǎo | 右→有（声调差异） |

### 1.2 同音词问题

| 拼音 | 同音词 | 歧义 |
|------|--------|------|
| shàng | 上/尚/伤/赏/商 | 都可能被识别为"上" |
| zuǒ | 左/作/坐/座 | 都可能被识别为"左" |
| yòu | 右/又/有/友 | 都可能被识别为"右" |
| xià | 下/夏/吓/厦 | 都可能被识别为"下" |

### 1.3 表达多样性

| 意图 | 可能表达 |
|------|---------|
| 向上 | 上/向上/往上/走上面/滑上面/往上移 |
| 向左 | 左/向左/往左/走左边/滑左边/往左移 |

## 二、技术方案

### 2.1 三层匹配策略

```
输入文本 → 精确匹配 → 拼音匹配 → 相似度匹配 → 命令
```

**优先级**：
1. **精确匹配**（优先级最高）：文本完全包含关键词
2. **拼音匹配**（口音容错）：拼音相似度 ≥ 0.6
3. **相似度匹配**（兜底）：文本相似度 ≥ 0.7

### 2.2 词表设计原则

```typescript
interface Command {
  direction: 'up' | 'down' | 'left' | 'right';
  keywords: string[];  // 关键词（含口音变体）
  pinyins: string[];   // 拼音（含方言变体）
}

const COMMANDS: Command[] = [
  {
    direction: 'up',
    keywords: [
      // 标准表达
      '上', '向上', '往上', '走上面',
      // 口音变体（同音词）
      '尚', '伤', '赏', '商',  // shang音
      '桑', '丧',              // sang音（南方口音）
    ],
    pinyins: [
      'shang',  // 标准拼音
      'sang',   // 南方口音（sh→s）
      'shan',   // 部分地区（ang→an）
    ],
  },
  // ... 其他方向
];
```

### 2.3 拼音模糊匹配

**算法**：编辑距离（Levenshtein Distance）

```typescript
function similarity(a: string, b: string): number {
  const dist = editDistance(a, b);
  const maxLen = Math.max(a.length, b.length);
  return 1 - dist / maxLen;
}

// 示例
similarity('shang', 'sang')  // 0.8 (sh→s，差一个字母)
similarity('zuo', 'zhuo')    // 0.75 (插入h)
```

**为什么有效？**
- 口音差异通常只改变1-2个字母
- `shang → sang`：sh→s（1个字母差异）
- `zuo → zhuo`：插入h（1个字母差异）

## 三、完整实现

### 3.1 核心类

```typescript
export class Voice2048Controller {
  private options = {
    confidenceThreshold: 0.7,      // 文本相似度阈值
    cooldownMs: 500,               // 冷却时间（防连续触发）
    enablePinyinMatch: true,       // 启用拼音匹配
    pinyinSimilarityThreshold: 0.6, // 拼音相似度阈值
  };

  process(result: ASRResult): Command | null {
    const text = result.text.trim();
    
    // 1. 精确匹配
    for (const cmd of COMMANDS) {
      for (const keyword of cmd.keywords) {
        if (text.includes(keyword)) {
          return this.trigger(cmd);
        }
      }
    }
    
    // 2. 拼音匹配
    const textPinyin = toPinyin(text).join('');
    for (const cmd of COMMANDS) {
      for (const cmdPinyin of cmd.pinyins) {
        if (similarity(textPinyin, cmdPinyin) >= 0.6) {
          return this.trigger(cmd);
        }
      }
    }
    
    // 3. 相似度匹配
    for (const cmd of COMMANDS) {
      for (const keyword of cmd.keywords) {
        if (similarity(text, keyword) >= 0.7) {
          return this.trigger(cmd);
        }
      }
    }
    
    return null;
  }
}
```

### 3.2 冷却机制

**问题**：用户说一次"上"，ASR可能返回多个partial结果，导致连续触发。

**解决**：
```typescript
private lastTriggerTime = 0;

private trigger(cmd: Command): Command | null {
  const now = Date.now();
  if (now - this.lastTriggerTime < this.options.cooldownMs) {
    return null;  // 冷却中，跳过
  }
  this.lastTriggerTime = now;
  cmd.action();
  return cmd;
}
```

## 四、性能优化

### 4.1 词表优化

**问题**：每次匹配都遍历所有关键词，O(n×m)复杂度。

**优化**：构建Trie树或倒排索引

```typescript
// 简化版：使用Map加速精确匹配
const keywordMap = new Map<string, Command>();
for (const cmd of COMMANDS) {
  for (const keyword of cmd.keywords) {
    keywordMap.set(keyword, cmd);
  }
}

// 精确匹配：O(1)
const cmd = keywordMap.get(text);
```

### 4.2 VAD端点检测

**问题**：持续监听浪费资源，容易误触发。

**解决**：使用VAD检测语音端点

```typescript
import { EnergyVAD } from '@voice-kit/scene-input';

const vad = new EnergyVAD({
  threshold: 0.02,
  minSpeechMs: 200,   // 最短语音时长
  minSilenceMs: 700,  // 静默判定时长
});

// 只在检测到语音时才发送ASR
for await (const event of vad.events()) {
  if (event.kind === 'speech-start') {
    startRecording();
  } else if (event.kind === 'speech-end') {
    stopRecordingAndRecognize();
  }
}
```

### 6.3 上下文增强

**问题**：单次识别可能有误，需要上下文辅助。

**解决**：滑动窗口 + 投票

```typescript
class ContextAwareController {
  private recentResults: string[] = [];
  private windowSize = 3;

  process(text: string): Command | null {
    this.recentResults.push(text);
    if (this.recentResults.length > this.windowSize) {
      this.recentResults.shift();
    }

    // 投票：最近3次识别结果中出现最多的命令
    const votes = new Map<string, number>();
    for (const t of this.recentResults) {
      const cmd = this.match(t);
      if (cmd) {
        votes.set(cmd.direction, (votes.get(cmd.direction) ?? 0) + 1);
      }
    }

    // 需要超过半数才触发
    for (const [direction, count] of votes) {
      if (count > this.windowSize / 2) {
        return this.getCommand(direction);
      }
    }

    return null;
  }
}
```
