## 背景

Phase 6 NLLB-200-distilled-600M Route C (L0H15) F1=0.851（金标准 8 case），距百度人感 ~95% 仍差 10%。

Phase 8 = 用户标注驱动的 alignment head 微调闭环。
本 PR（MVP）：脚手架 + 数据准入门槛 + dry-run 友好；**真实训练数据尚无，等标注采集**。

## 关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| alignment head | L0 H15 | Phase 6 content-only sharpness 最高，F1=0.851 |
| 冻结策略 | encoder + decoder 全部，仅 q_proj/k_proj 解冻 | 方案 §6.2「不动 encoder/decoder 主体」 |
| NLLB cross-attn 定位 | `decoder.layers[L].self_attn` | NLLB 用统一 self_attn 模块处理 cross-attn（src 经 encoder 作 K/V） |
| 冲突阈值默认 | 0.30（方案文档） | 与 §6.4 一致 |
| 质量权重 | heavy ≥50 → 2.0 / new <10 → 0.5 / normal → 1.0 | 与 §6.4 一致 |
| 优化器 | AdamW lr=1e-5 | 经典小学习率方案；微调 alignment head 无需大学习率 |
| Baseline F1 | 0.851 | Phase 6 结论，changes/2026-06-24-phase6-nllb.md |
| A/B 阈值 | ±0.02 | 方案 §6.3「F1 提升 > 0.02」 |
| Dry-run | 跳过 NLLB 加载 + pred=gold | CI / 本机无 GPU 友好 |
| Random seed | 42 | 可复现（PyTorch + random） |

## 不做

- **不下载 NLLB**：本机无 GPU，自动 fallback 到 mock。生产训练必须 GPU + 完整模型。
- **不动 NestJS 后端**（Agent 6 已完成）：`server/annotation/` 仅作为数据源（HTTP /v1/annotations/export）
- **不动 server/nmt_server.py**：Phase 7-A FastAPI 服务保持不变
- **不重 Phase 6 fixture**：`test/fixtures/nllb-crossattn-gold.json` 是 Phase 6 交付物，直接复用

## 遗留问题

1. **真训练数据缺**：等标注采集 ≥500 条后做 A/B
2. **GPU 环境**：未在本机跑通真训练（macOS + 无 CUDA）；需要在 Linux + GPU 上验证
3. **过拟合防护**：当前未加 weight decay / early stopping；标注数据小时容易过拟合 q_proj
4. **batch 内对齐 token 索引**：当前实现假设 user_alignments_per_example 用 src 索引直接对应；真训练时需要重新映射（去掉 lang code + 特殊 token）
5. **cross-attn 提取**：`finetune_align_head.py` 用了 `model.generate(output_attentions=True)`，完整 forward 会更准；但 spike 不强求
