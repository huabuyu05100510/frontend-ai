## 关键发现
1. **NLLB-200-distilled-600M 翻译修复 4/8 case 的错误**（C3 多"好"、C7 "模式"→"模型"、C8 重复"天气"、C1 "懒懒狗"消失）
2. **alignment head 分析必须 content-only**：第一次按全 src 行 max attention 选的 4 头全 0（attention 在 `</s>` 上聚集）
3. **NLLB 最佳 head L0H15**（content-only sharpness 0.84），threshold=0.1（远低于 MarianMT 的 0.3）
4. **NLLB Route C 单路 F1=0.851**，超 Phase 5 ensemble 0.781，超 Phase 2 Route A 0.841
5. **强模型下 ensemble 失效**：NLLB Route C 已 0.851，LaBSE Route A（0.69）投票反而拉低
