## 可观测性

3 个组件全部输出 JSON 结构化日志（`xt:bg`、`xt:content`、`xt:injector`、`xt:labse`）：
- `xt:bg`: backend selected / api key loaded (masked) / batch progress / align ok | fail
- `xt:content`: 段提取数、调度批次、完成进度
- `xt:labse`: 模型加载耗时 / 单次 align 耗时 / cache 命中

## 已知遗留（W2 入口）

1. **LaBSE WordPiece 子词碎片化**（`as / ##ync / ##hronous`）
   - 影响：英文长词 hover 时拆成多个 span
   - 修法：server 层合并 `##`-前缀；或切到 MarianMT/NLLB tokenization（Phase 5/6 已验证）
2. **Playwright MV3 SW attach 不稳**
   - Chrome 149 + Playwright 不稳定；W1-5 e2e 改用 chrome.* mock
   - W2 排查：Playwright Chromium vs Chrome 149 / 试 puppeteer-core
3. **popup UI 缺 backend 切换 + 对齐开关**
   - 当前只能在 chrome.storage.local 手动写
   - 影响：普通用户无法切 backend / 关对齐
4. **对齐 score 未做阈值过滤**
   - 短句场景（"I love you"）"The" 会同时映射多个汉字
   - 修法：在 `findPairs` 里加 score ≥ 0.5 过滤
5. **LaBSE server 部署形态**
   - 当前本地 Node 进程；正式发布需要：①打包 ONNX runtime 进扩展（体积大）②ort-web 浏览器内（首屏慢）③保留 server 模式仅 dev
